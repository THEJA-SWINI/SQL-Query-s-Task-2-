# SQL-Query-s-Task-2-
Objective
Practice using aggregate functions, GROUP BY, and HAVING to analyze data stored in a database.

Task
Create a database table named employees with the following columns:
employee_id
employee_name
department
salary
experience
city
Insert at least 15 employee records with different departments, salaries, experience levels, and cities.
Write SQL queries to solve the following:
Part A – Aggregate Functions
Find the total number of employees.
Find the total salary of all employees.
Find the average salary of employees.
Find the highest salary.
Find the lowest salary.

Part B – GROUP BY
Find the number of employees in each department.
Find the average salary of each department.
Find the highest salary in each department.
Find the lowest salary in each department.
Find the total salary paid by each department.
Find the number of employees in each city.

Part C – HAVING
Find departments having more than 3 employees.
Find departments where the average salary is greater than 40,000.
Find departments where the total salary is greater than 2,00,000.
Find cities having more than 2 employees.
